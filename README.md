# 🏡 US House Price Predictor

## Project Overview

The **US House Price Predictor** is a machine learning web application that estimates the selling price of residential properties in the United States based on key property characteristics. The application is built with **Streamlit** and powered by a **Ridge Regression** model trained on over one million real estate listings.

Users can enter property information such as the number of bedrooms, bathrooms, house size, lot size, state, and city to receive an estimated market value.

---

# Dataset

The model was trained on a large US residential real estate dataset containing more than one million property listings.

The dataset includes information such as:

* Selling price
* Number of bedrooms
* Number of bathrooms
* House size (square feet)
* Lot size (square feet)
* City
* State

### Data Preprocessing

The dataset underwent several preprocessing steps before model training:

* Removed duplicate records
* Removed observations with unrealistic values
* Handled missing values using median imputation for numerical features
* One-hot encoded categorical variables (City and State)
* Log-transformed skewed numerical features
* Log-transformed the target variable (Price)
* Standardized numerical features
* Engineered a new feature:

  * **sqft_per_bed = house_size / bed**

---

# Features

The model uses the following input features:

* Bedrooms
* Bathrooms
* House Size (sqft)
* Lot Size (sqft)
* City
* State
* Square Feet per Bedroom (`sqft_per_bed`)

---

# Model

The prediction model was built using **Scikit-learn**.

### Algorithm

* Ridge Regression

### Machine Learning Pipeline

The model pipeline includes:

* Median Imputation
* Log Transformation of skewed numerical features
* Feature Scaling using StandardScaler
* One-Hot Encoding of categorical features
* Ridge Regression

The entire preprocessing workflow and model were combined into a single Scikit-learn pipeline to ensure consistent preprocessing during both training and prediction.

---

# Model Performance

Performance was evaluated on an unseen test dataset.

| Metric       |       Value |
| ------------ | ----------: |
| Baseline MAE | $214,309.83 |
| Training MAE |  $92,698.28 |
| Test MAE     |  $93,639.38 |
| RMSE         | $157,347.37 |
| R² Score     |      0.7266 |

These results indicate that the model substantially outperforms the baseline predictor while explaining approximately **72.7%** of the variance in house prices.

# Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/house-price-predictor.git
```

### 2. Navigate to the project folder

```bash
cd house-price-predictor
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Launch the Streamlit application

```bash
streamlit run app.py
```

The application will open automatically in your default web browser.
